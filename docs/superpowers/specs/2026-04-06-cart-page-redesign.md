# 購物車頁面重設計 — 緊湊精品感 + Sticky 結帳

> 砍冗餘、壓密度、sticky 結帳列，一屏完成結帳流程

## 1. 問題

從截圖和程式碼看到的冗餘：

1. **標題重複** — `PageHero` 和 `CartPageContent` 各有一個「購物車」標題，浪費 ~60px
2. **內容鬆散** — 商品列表、摘要、結帳按鈕之間間距大，缺乏結構感
3. **商品行佔空間** — 圖片 80px + 資訊分兩行（名稱+價格 / stepper+小計），每件商品吃 ~100px 高
4. **逐行小計冗餘** — 每件商品右下角顯示 `NT$xxx` 小計，底部合計又顯示一次
5. **摘要和結帳按鈕分離** — 視覺上像兩個獨立區塊，不像一個連貫的結帳流程
6. **結帳按鈕可能被滑出視窗** — 商品多時需要滑動才能看到按鈕

## 2. 設計方案

### 2.1 整體結構

```
┌─────────────────────────────────┐
│  購物車 (2)          繼續選購 → │  ← 單一標題行，取代 PageHero + 內部標題
├─────────────────────────────────┤
│                                 │
│  [img] 手作杏仁瓦片             │  ← 可滑動商品列表
│        NT$105  [−] 1 [+]    ✕  │
│  · · · · · · · · · · · · · · · │
│  [img] 綜合堅果塔               │
│        NT$280  [−] 2 [+]    ✕  │
│                                 │
│  ┌─ 完整摘要（滑動時被蓋住）─┐  │
│  │ 小計 (3 件)      NT$665  │  │
│  │ 運費             待結算   │  │
│  └───────────────────────────┘  │
│                                 │
│  (底部留白給 sticky 區塊)       │
├═════════════════════════════════┤  ← sticky bottom-0
│  合計 (3 件)          NT$665   │
│  ┌─────────────────────────────┐│
│  │         前往結帳            ││
│  └─────────────────────────────┘│
│     有問題？透過 LINE 聯繫我們  │
└─────────────────────────────────┘
```

### 2.2 頁面層級變更

#### 砍掉 PageHero

購物車頁面移除 `<PageHero title="購物車" />`，標題行由 `CartPageContent` 內部的 header 行負責（已存在，只需保留）。

`app/(store)/cart/page.tsx` 變更：
- 移除 `PageHero` import 和使用
- 只保留 `<CartPageContent />`

### 2.3 商品行壓縮

#### 現狀 → 目標

| 屬性 | 現狀 | 目標 |
|------|------|------|
| 圖片尺寸 | 80×80px | 64×64px |
| 圖片圓角 | `rounded-xl` | `rounded-lg` |
| 行高 | ~100px（兩行資訊） | ~80px（壓縮排列） |
| 逐行小計 | 顯示 `NT$xxx` | 移除（合計已在底部） |

#### 商品行佈局

```
┌──────┬──────────────────────────────┐
│      │ 手作杏仁瓦片              ✕  │  ← 名稱 + 刪除按鈕
│ 64px │                              │
│      │ NT$105   [−] 1 [+]          │  ← 單價 + stepper
└──────┴──────────────────────────────┘
```

- 名稱行：商品名左對齊，刪除按鈕（✕）右對齊
- 價格行：單價左對齊，stepper 靠右（但不靠最右，給視覺呼吸）
- 移除逐行小計 — 底部合計已涵蓋，逐行顯示是冗餘資訊
- 已下架商品的「商品已下架」紅字提示保留，顯示在名稱下方

#### 分隔線

商品之間用 `divide-y divide-sandrift-100/60` 保持不變（已經是虛線感的淡色分隔）。

### 2.4 摘要區塊

保留完整摘要（小計、運費、合計）在商品列表下方，作為靜態內容：

```
┌─────────────────────────────┐
│ 小計 (3 件)       NT$665    │  text-sandrift-600
│ 運費              待結算    │  text-sandrift-400
│ ─────────────────────────── │  border-t
│ 合計              NT$665    │  font-semibold text-sandrift-900
└─────────────────────────────┘
```

- 保留 `rounded-2xl bg-sandrift-50/30 ring-1 ring-sandrift-100/30` 卡片樣式
- 商品少時（一屏放得下），這個摘要和 sticky 區塊都可見，摘要提供完整明細
- 商品多時滑動，摘要被 sticky 蓋住，但 sticky 有精簡版合計

### 2.5 Sticky 結帳列

#### 定位方式

使用 `sticky bottom-0`，留在頁面流中但固定在視窗底部。

**為什麼不用 `fixed`：** fixed 脫離文件流，需要手動計算底部 padding 防止內容被遮擋，而且要處理跟 `StoreCta`（手機版 sticky CTA）的層級衝突。sticky 自然佔位，不需要額外計算。

#### 內容

```
┌─────────────────────────────────┐
│  合計 (3 件)          NT$665   │  ← 精簡一行合計
│  ┌─────────────────────────────┐│
│  │         前往結帳            ││  ← 按鈕
│  └─────────────────────────────┘│
│     有問題？透過 LINE 聯繫我們  │  ← LINE fallback
└─────────────────────────────────┘
```

- 精簡合計行：只顯示 `合計 (N 件)` + 金額，不重複小計和運費
- 結帳按鈕：同現有樣式 `bg-sandrift-500 rounded-xl`
- LINE 連結：保持不變

#### 視覺規格

| 屬性 | 值 |
|------|-----|
| 背景 | `bg-white/95 backdrop-blur-md` |
| 上邊框 | `border-t border-sandrift-100` |
| 陰影（滑動時） | `shadow-[0_-4px_12px_rgba(0,0,0,0.05)]` |
| 陰影（不滑動） | 無 |
| 內距 | `px-4 pt-4 pb-5` （底部多留給安全區域） |
| safe area | `pb-[env(safe-area-inset-bottom)]` 加在 pb-5 之外 |

#### 滑動陰影偵測

用 IntersectionObserver 監測一個 sentinel 元素（放在摘要區塊底部）：

- sentinel 可見 → sticky 無陰影（商品列表沒有被滑出視窗）
- sentinel 不可見 → sticky 加上陰影（表示有內容在 sticky 下方被遮擋）

陰影用 `transition-shadow duration-200` 過渡。

### 2.6 StoreCta 衝突處理

現有 `StoreCta` 是手機版的全局 sticky 購物車按鈕。在購物車頁面：

- **隱藏 StoreCta** — 購物車頁面已經有完整的結帳流程，不需要再顯示「前往購物車」的 CTA
- 在 `StoreCta` 元件加上路由判斷：`pathname === '/cart'` 時不渲染

### 2.7 空購物車

`CartEmpty` 元件不變 — 它有自己的精品感設計（玻璃卡片 + 浮動動畫），跟本次重設計不衝突。空狀態時不顯示 sticky 結帳列。

### 2.8 骨架屏

更新 hydration 骨架屏以匹配新佈局：
- 移除頂部標題骨架（標題行在 hydration 前就能顯示）
- 商品行骨架：64px 圓角方塊 + 兩行文字
- 底部 sticky 骨架：一行文字 + 按鈕形狀

## 3. 元件異動

| 元件 | 變動 |
|------|------|
| `app/(store)/cart/page.tsx` | 移除 `PageHero`，只渲染 `CartPageContent` |
| `components/cart/cart-page-content.tsx` | 重構佈局：商品列表 + 靜態摘要 + sticky 結帳列；加入 IntersectionObserver 陰影邏輯 |
| `components/cart/cart-item-row.tsx` | 圖片縮小 64px、移除逐行小計、壓縮排列 |
| `components/cart/cart-summary.tsx` | 不變（靜態摘要保留原樣） |
| `components/cart/cart-sticky-checkout.tsx` | **新增** — sticky 結帳列（合計 + 按鈕 + LINE 連結） |
| `components/store-cta.tsx` | 加入 `pathname === '/cart'` 隱藏判斷 |

## 4. 邊界情況

| 情境 | 行為 |
|------|------|
| 購物車空 | 顯示 `CartEmpty`，不顯示 sticky 結帳列 |
| 只有 1 件商品 | 一屏放得下，sticky 自然貼底，摘要和 sticky 合計都可見 |
| 5+ 件商品需要滑動 | sticky 固定底部，滑動時出現上陰影 |
| 所有商品已下架 | 結帳按鈕 disabled，sticky 仍顯示但按鈕灰色 |
| hydration 未完成 | 顯示骨架屏，sticky 區塊顯示骨架 |
| 桌面寬螢幕 | `max-w-3xl mx-auto` 限制寬度，sticky 同樣限寬 |

## 5. 不做的事

- ❌ 商品行滑動刪除（swipe-to-delete）— 有 ✕ 按鈕就夠
- ❌ 動態運費計算 — Phase 1 不支援
- ❌ 優惠券輸入框 — Phase 1 不支援
- ❌ CartEmpty 重設計 — 已有精品感，不在本次範圍
- ❌ 桌面版雙欄佈局 — 商品少，單欄足夠
